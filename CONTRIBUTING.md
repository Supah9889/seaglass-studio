# Contributing

Report bugs and propose changes in GitHub Issues. Include reproducible steps, actual and expected behavior, and relevant app and OS versions. Use small, focused pull requests and explain what you verified.

Run `npm test` for editor changes and `cargo test --manifest-path src-tauri/Cargo.toml --locked` for desktop changes. Test drawing and save/reopen with disposable artwork. Run `npm run notices` and review the resulting third-party notices when dependencies change.

Submit only code or assets that you have the rights to contribute. Include attribution and applicable license terms for third-party material.
